## Project Objective
Analyze Seoul bike-sharing demand, identify operational patterns, study weather/seasonal effects, and create business recommendations.

## Workflow
1. Python + Pandas
2. BeautifulSoup
3. PostgreSQL
4. Excel
5. Power BI
6. Findings + 3 recommendations
7. GitHub

## Files
- `data_cleaned.csv` — cleaned/derived dataset
- `python_analysis.py` — Pandas analysis
- `scrape_attractions.py` — BeautifulSoup scraper
- `seoul_attractions.csv` — generated by scraper
- `bike_sharing_analysis.xlsx` — Excel analysis workbook
- `sql/business_queries.sql` — five business queries
- `POWER_BI_DASHBOARD.md` — Power BI dashboard specification
- `FINAL_FINDINGS.md` — final findings and exactly three recommendations
